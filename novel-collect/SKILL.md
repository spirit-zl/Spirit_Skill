# 小说全本采集（novel-collect）

用户给一个**任意章节**的链接，产出**一个** Markdown 文件：文件名是小说名，每章一个 `## 章节名`，
正文纯文本（除了两级标题不引入任何 Markdown 格式），广告与截断提示自动删除，最后自检。

## 什么时候用

- "把这个小说全部下载下来，合并成一个 md"
- "这些链接的小说抓全本，章节名当标题，纯文本"
- "小说采集/导出/转 markdown"

## 快速开始

```bash
python3 scripts/novel_collect.py "<任意章节链接>" -o "<输出目录>"
```

常用参数：

| 参数 | 作用 |
|---|---|
| `-o DIR` | 输出目录（默认当前目录） |
| `--workers N` | 并发数，默认 6；站点限流时降到 2 |
| `--limit N` | 只抓前 N 章，用于试跑验证适配器 |
| `--refresh-toc` | 忽略已缓存目录，重新抓 |
| `--check-only` | 只跑自检不写文件 |
| `--data-dir DIR` | 缓存与目录根（默认 `~/.workbuddy/data/novel-collect`） |

过程三句话：**抓目录 → 逐章落缓存 → 清洗合并 + 自检**。缓存可续跑，中断重跑不会重复下载。

## 输出规格（固定，不要随意改）

- 文件：`<小说名>.md`，与工作目录同级
- 首行：`# 小说名`
- 每章：`## 章节名` + 空行 + 正文段落（段落之间空一行）
- **除 `#` 和 `##` 外不允许出现任何 Markdown 语法**：不加粗、不链接、不列表、不引用、不代码块、不表格
- 不写作者、来源、生成时间等页眉页脚信息（保持"除了标题没有任何其他格式"）

## 清洗规则（`clean_text()`）

按"站点广告"逐条正则删除，注意两种情况：

1. **行尾内联**——广告接在正文最后一段后面，例如
   `（未完待续）[笔趣看  www.biqukan.com]百度搜索"笔趣看小说网"手机阅读：m.biqukan.com`
   `笔趣阁阅读网址：wap.blqukan.cc`
   所以必须**按模式替换**，不能只按"整行匹配"删除。
2. **独立的截断提示段**——`(本章未完,请翻页)`、`本章未完，点击下一页继续阅读。`、
   `请关闭浏览器的畅读模式……`、`原网页地址：http://...`

另外做 Markdown 无害化：`*` → 全角 `＊`（原文的 `[***]` 屏蔽标记才不会渲染成粗体），
行首 `#`/`>`/`|` 前加全角空格，删除乱码反引号串。

章末再走一遍 `tidy_tail()`：若结尾不是句末标点，先剥掉尾部拉丁字母/悬空逗号碎片，
再裁到最后一个句子边界。**只处理结尾异常**，不动正文中间的断句；
作者自己在章末写的「求票」等话属于原文，**要保留**（除非用户明确要求删）。

**新增站点只需往 `NOISE_PATTERNS` 加正则**，不必改流程。

## 自检（`self_check()`）

合并后自动报告并给结论，全部通过才算完成：

- 章节标题数 == 目录章节数
- 总字数、单章字数分布（最短/平均/最长），过短章节（<50 字）必须为 0
- 噪声残留扫描（`本章未完` / `阅读网址` / 站点域名 / `请翻页` / `原网页地址` / `未完待续`）必须为 0
- 格式扫描（粗体/斜体成对/链接/图片/引用/代码块/分隔线/表格/HTML 标签）必须为 0
- 空缓存文件检查

退出码：`0` 通过，`2` 有问题。

## 已支持的站点与各自的关键坑

### zhdu7.net（公益书屋）

- 编码 UTF-8；目录在 **`/txtlist/<book>.html`**，条目形如
  `<a href="/txt/<book>/<cid>.html"><dd>章节名</dd></a>`；目录**分页**（`/txtlist/<book>/2.html`…）
- 正文两份：明文 `#booktxt`（**掺着广告段**）和脚本里的
  `document.getElementById('booktxt').innerHTML = str_decode("<base64>")`（**干净**）。
  优先解 base64。
- 一章分多页，`<h1>` 里带 `（1/4）`；翻页靠 `id="next_url"`，末页文案变成「下一章」。
- **坑**：Cloudflare 会因请求过密返回 `403 访问受限`（body 只有 4 个字），且持续数小时不解除。
  一旦命中就**不要继续硬刷**，换镜像源（见下）。

### wap.blqukan.cc（笔趣看）

- 编码 **GBK**（`decode_html` 会按 meta 自动选）
- 目录 `/4/<g>/<book>/`，**分页 87 页**（`/4/<g>/<book>_2/`），章节列表在 `最新章节列表</dt>…</dl>` 里
- 正文 `#chaptercontent`；`（1/3）` 分页，子页是 `<cid>_2.html`
- 噪声是**行尾内联**的三种：`(本章未完,请翻页)`、`笔趣阁阅读网址：wap.blqukan.cc`、
  `（未完待续）[笔趣看  www.biqukan.com]百度搜索…`

### ibxsw.com（不二读书）

- 目录 `/book/<id>.html`，全部章节在 `<dd class="col-md-3">` 里
- **最大的坑（务必先读）**：正文有两份——
  ① 可见的 `<div id="booktxt">`：**只有约 350 字的截断片段**，直接用它会让每章只剩三分之一、结尾停在半句；
  ② 脚本里的 `document.getElementById('booktxt').innerHTML = str_decode("<base64>")`：**这才是完整正文**。
  `_body()` 必须优先 base64，且比较时要比**纯文本长度**而不是原始 HTML 长度
  （base64 版带标签反而更短，比 HTML 长度会误选截断版）。
  实测同一章：截断版 1472 字 / base64 版 2706 字。
- **第二个坑**：目录里可能有大段章节**没有超链接**（只给标题不给 href），但正文页其实存在。
  这些章节的 ID 既不连续、也不保证与目录顺序一致（站点补更导致），区间探测只能补回约 86%，
  剩下要用「章号 → ID」定位：
  - 先用相邻已知章节做**局部插值**（比全局线性回归准得多），在 ±30 范围内强探测；
  - 目录存在**重号章节**（如两个「第1516章」）和**标题笔误**（目录写 1516、页面实为 1526），
    所以匹配要「标题全等 → 章号相等」两级回退。
- **第三个坑**：`idmap` 里把超时记成 `None` 会永久跳过该 ID。探测失败**不要缓存为 None**，
  或者修复轮强制重试。
- 正文噪声块是 `data-id="9997"`（原网页地址）和 `data-id="9999"`（畅读模式提示）
- 分页 `_2.html`；页面标题 `书名(作者)_章节名（i / N）_…`，空页标题里章节名为空
  ；超过总页数的 `_N.html` 会重复返回最后一页，可用来确认「已到章末」
- 性能与限流：并发 24～32 时约 2.5～6 req/s，**超时率 15-30%**（超时设 8-10 秒、失败重试 3-4 次）
- 站点的「字数」字段不可信（自称 457 万，实际抓到 866 万），以实际抓取为准

### 站被封时怎么换源

同源镜像的判定方法：**目录总章数一致**（如 2284 章）+ **章节标题逐条一致**。
注意区分"连载版"与"出版删改版"——后者章数少、开头会混进卷名（如 `01改变命运的支点` / `■大梦初醒`）
且内容经过编辑压缩，**不能混用**。

## 新增站点适配器

继承 `BaseSite`，实现三个方法即可：

```python
class XxxSite(BaseSite):
    name = "xxx"
    hosts = ("example.com",)          # 域名匹配
    def book(self):     ...           # -> {"title","author","toc_url","total"}
    def chapters(self): ...           # -> [{"id","title","url"}]
    def chapter_paras(self, ch): ...  # -> 段落列表（内部用 clean_text + strip_html）
```

然后加进 `SITES = [Zhdu7Site, BlqukanSite, IbxswSite, XxxSite]`。
`chapter_paras` 里只负责"取原始 HTML 片段 + 翻页拼接"，**清洗一律交给 `clean_text()`**，
这样新站点的广告只需补充正则。
