# 想象文学类 · Q1–Q5 提示词模板

适用：小说、史诗、戏剧等虚构文学作品。

用法：按 Q1 → Q5 顺序逐节生成。把下文 Prompt 中的《书名》替换为实际书名，然后以该书的
作者/内容专家视角直接产出内容，每节写入独立文件 `parts/0N-<节名>.md`（见 SKILL.md 工作流）。
每节文件以部分标题开头（`## 一、本书简介` 式：中文序号 + 节名），部分内用 `###`/`####` 层级。
格式适配说明见 `conventions.md`。

---

## Q1 · 本书简介

**Prompt**

请简单介绍《书名》这本书，并提供有关该书的详细信息，例如书名、作者、出版社、出版日期和主题等。您的回答应该涵盖该书的重点和亮点，并提供足够多的细节来支持您的观点。请注意，您的回答应该具有简洁性和精确性，并能够吸引读者的兴趣。

**输出要求**

以 Markdown 源码格式写入本节文件（不使用代码围栏）。首行写本节的部分标题（`## <中文序号>、<节名>`，如 `## 一、本书简介`）；部分内第一级用 `###`、第二级用 `####`，以此类推；不要出现 `#` 级标题。

---

## Q2 · 情节与结构

**Prompt**

请详细分析并总结小说《书名》的主要情节和结构。包括以下几个方面：

1、小说的开头：描述故事的初始情况和背景，以及如何引入主要角色和冲突；

2、发展过程：概述故事如何发展，主要事件和转折点是什么，以及它们如何推动情节向前发展；

3、高潮：指出故事的高潮部分，分析这一部分如何集中展示了故事的主要冲突和角色的挑战；

4、结局：描述故事是如何结束的，包括冲突的解决方式以及对主要角色的最终影响。

此外，考虑小说的结构是否包含任何特殊的组织方式，如多线程叙述、非线性时间线、或者其他独特的叙述技巧，并分析这些结构上的选择如何影响了故事的呈现和读者的体验。

**输出要求**

以 Markdown 源码格式写入本节文件（不使用代码围栏）。首行写本节的部分标题（`## <中文序号>、<节名>`，如 `## 一、本书简介`）；部分内第一级用 `###`、第二级用 `####`，以此类推；不要出现 `#` 级标题。

---

## Q3 · 人物与角色

**Prompt**

以作者的角度，请特别关注各个角色的性格特征、动机、发展变化以及他们之间的相互关系。请为每个主要角色和重要的次要角色创建详细的分析，包括：

1、角色的背景和性格描述；

2、角色在故事中的主要动机和目标；

3、角色如何随着故事发展而成长或变化；

4、角色之间的关系如何影响故事的发展和最终结果。

同时，考虑角色的行为和选择如何支持或推动小说的主题和情节。最后，请反思这些角色分析如何帮助你更深入地理解小说的深层主题和信息。

**输出要求**

以 Markdown 源码格式写入本节文件（不使用代码围栏）。首行写本节的部分标题（`## <中文序号>、<节名>`，如 `## 一、本书简介`）；部分内第一级用 `###`、第二级用 `####`，以此类推；不要出现 `#` 级标题。

---

## Q4 · 冲突与解决

**Prompt**

以作者的角度，请专注于识别和分析故事中的主要冲突以及如何解决这些冲突。请从以下几个方面构建你的分析：

1、描述小说中出现的主要冲突类型，包括人物内部冲突、人物与人物之间的冲突、人物与社会的冲突、人物与自然的冲突等；

2、详细解释这些冲突是如何通过故事情节发展被展示出来的，包括关键事件和转折点；

3、分析小说中的冲突是如何得到解决的，包括任何特殊的解决方案或教训，以及这些解决方案对角色成长和故事结局的影响；

4、反思这些冲突及其解决方案如何增强小说的主题和寓意，以及对你个人的启示或感悟。

请使用具体例子和引用来支持你的分析，以便更深入地理解小说的结构和深层含义。

**输出要求**

以 Markdown 源码格式写入本节文件（不使用代码围栏）。首行写本节的部分标题（`## <中文序号>、<节名>`，如 `## 一、本书简介`）；部分内第一级用 `###`、第二级用 `####`，以此类推；不要出现 `#` 级标题。

## Q5 · 主旨与寓意

**Prompt**

以作者的角度，详细介绍本书的中心主题和深层寓意。请从以下几个方面进行分析：

1、确定并描述小说的主要主题，包括它们是如何通过情节发展、角色行为和对话以及设置背景等被展现出来的；

2、探讨小说中的象征元素和意象，包括任何重复出现的符号或主题，以及它们是如何加深对主题的理解的；

3、分析小说如何对人性、社会、文化或道德问题提出质疑或提供评论；

4、反思这些主题和寓意对你个人的意义，以及它们如何影响你对小说的整体解读。请提供具体的例子和引用来支持你的分析，以展现小说深层次的主题和寓意。

**输出要求**

以 Markdown 源码格式写入本节文件（不使用代码围栏）。首行写本节的部分标题（`## <中文序号>、<节名>`，如 `## 一、本书简介`）；部分内第一级用 `###`、第二级用 `####`，以此类推；不要出现 `#` 级标题。
