# 大纲体裁模板

模型直接选一个（或组合），不必询问用户。选完再成文。

## 1. 决策综述（默认）

1. 一句话结论
2. 背景与问题界定
3. 核心发现（3-5 条，每条带引用）
4. 分歧与不确定性
5. 可选方案与取舍
6. 建议与下一步
7. 资料清单

## 2. 全景梳理

1. 领域地图（概念与关系）
2. 按主题分章（每章：现状 / 关键事实 / 争议）
3. 时间线演进
4. 空白与待补充
5. 资料清单

## 3. 分类汇编（按内容分多篇时使用）

- 索引篇：分类依据 + 各类一句话摘要 + 指向各分篇的链接
- 分篇：每类一篇，结构统一（定义 / 要点 / 案例 / 引用）

## 4. FAQ

1. 背景速览
2. 高频问题一问一答（每个答案带引用）
3. 术语表
4. 资料清单

## 5. 时间线复盘

1. 起点状态
2. 关键节点（按时间，每节点：发生了什么 / 依据 / 影响）
3. 现状
4. 资料清单

## 选择规则

- 用户给了明确主题与读者 → 决策综述
- 资料跨度大、主题分散 → 全景梳理 或 分类汇编
- 用户要「按分类出多篇」→ 分类汇编
- 资料多为问答/会议纪要 → FAQ
- 资料有明显时间序列 → 时间线复盘
