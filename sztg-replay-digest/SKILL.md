# 直播回放要点抓取与归档

你负责把一期直播回放变成一份可直接入库的要点稿，并只往目标飞书文档的**最前面**插入，旧内容一个字都不动。
不做行情预测、不做投资建议、不评价讲师水平。

## 使用前提

触发条件（任一满足）：

- 用户发来 `app.cn.sztg.com/zhibo.html?...` 这类直播间或回放链接；
- 用户说「趋势复利」「直播回放」「总结这场直播」，且对象是策牛科技平台；
- 用户要求把某期回放追加到趋势复利文档。

| 必须有 | 缺失时 |
|---|---|
| 回放链接或直播间地址 | 用配置里的默认直播间；仍无则问一句要链接 |
| 目标飞书文档 | 用配置里的 doc；无配置则问一次，并存进 config.json |

## 边界

| 遇到 | 不做 | 改做 |
|---|---|---|
| 页面要求扫码登录 | 不让用户每次登录 | 用持久化 profile；失效才出二维码，扫一次长期有效 |
| 回放是纯视频没有文字 | 不靠标题和猜测定稿 | 必须走音轨转写；转写失败就如实报错，不编内容 |
| 讲师口播数字听不清 | 不猜、不圆成整数 | 标「待确认」，或只保留能确定的那个数 |
| 文档里已有同日期一期 | 不重复插入 | 直接跳过，退出码 3 |
| 用户要改以前某一期 | 不在本技能范围内 | 说明本技能只做前插，改旧内容需单独授权 |

## 流程

1. **体检**：`python3 scripts/doctor.py`。退出码 1 说明有缺失，先按提示补齐（缺 ffmpeg 用 `python3 -m pip install imageio-ffmpeg`）。
2. **看登录态**：`node scripts/capture.cjs status`。退出码 0 直接进第 3 步；退出码 4 才出二维码：`node scripts/capture.cjs qr --out ~/files/sztg-qr.png`，把图给用户扫，扫完它会自己返回 0。
3. **列出回放**：`node scripts/capture.cjs list`，确认要抓的是哪一期（标题 + 时间）。
4. **抓取**：`node scripts/capture.cjs fetch --index 0 --outdir ~/.workbuddy/data/sztg-replay/work-<日期>`。产出 `audio.mp3` 与 `meta.json`（含日期、时长、分片数）。要指定某期用 `--date 2026-11-12`。
5. **转写**：对 `audio.mp3` 调 AudioTranscribe，拿到带时间戳的逐句文本。整段一次投，不要切片。
6. **成稿入库**：
   - 按 `references/doc-format.md` 写 `episode.json`（三章、第一人称、不用引号）；
   - `python3 scripts/render_xml.py episode.json -o episode.xml`；
   - `python3 scripts/push_feishu.py --xml episode.xml --date <YYYY-MM-DD>`，它会先查重、再前插、再回读校验。

## 硬约束

1. **只前插**：写入位置固定为文档开头（`block_insert_after --block-id 0`）。不要用 append，不要 overwrite，不要动旧 block。
2. **日期倒序**不靠排序实现，靠「新的插到最前」自然形成；所以绝不能插错位置。
3. **标题固定**为 `趋势复利（YYYY-MM-DD）`，不加斜体说明、不加副标题。
4. **内容规范**见 `references/doc-format.md`：三章、第一人称、零引号、不确定处用括号、表格不超过 8 列。
5. **不编纂**：转写里没有的个股、价位、战绩一律不写；口播与盘面数据冲突时，两边都写清。

## 失败处理

| 现象 | 退出码 | 处理 |
|---|---|---|
| 登录态失效 | 4 | 出二维码让用户扫一次，不要反复要求登录 |
| 找不到指定日期那期 | 3 | 打印现有列表，让用户确认要哪一期 |
| 抓不到 m3u8 | 6 | 等 10 秒重试一次；仍失败说明回放未上传或权限不足，如实报告 |
| 文档里已存在同日期 | 3 | 跳过，不重复插入 |
| 写入后首个一级标题不是本期 | 6 | 说明写入位置异常，回读文档确认，不要盲目重写 |

## 自检

交付前逐条确认：

- [ ] 文档首个一级标题是本期 `趋势复利（日期）`，旧各期仍在其后且未被改动；
- [ ] 三章齐全，没有第四部分、没有免责声明章节（用户要求省略）；
- [ ] 全文零引号（用脚本统计，不靠肉眼）；
- [ ] 每个个股都有方向、位置、理由，缺失的标「待确认」；
- [ ] `meta.json` 的日期与标题里的日期一致。
