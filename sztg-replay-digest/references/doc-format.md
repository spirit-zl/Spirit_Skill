# 一期内容的写作与排版规范

这套规范来自用户 2026-11-13 定稿，后续每一期都照此执行，不要自行调整。

## 一、文档骨架

每期是文档里的一个一级段落，只含三章：

```
# 趋势复利（YYYY-MM-DD）
讲师：姓名（投顾执业编号 XXXXX）｜机构｜HH:MM 场次｜回放 X 分 XX 秒

## 一、大盘情绪判断
## 二、交易方法
## 三、个股区间与理由
```

- 标题只写 `趋势复利（日期）`，**不加斜体说明、不加副标题、不加免责声明章**。
- 标题下面紧跟一行 meta（讲师、编号、机构、场次时间、回放时长），它是普通段落，不是小标题。
- 除这三章外不要再出现第四部分；需要提示风险时并入正文一句，不单开章节。

## 二、人称与引号

1. **用讲师第一人称写**：主语是「我」，不是「她」「讲师认为」「他表示」。
2. **全文不用引号**（中文引号、英文引号、单引号都不用）。要复述原话时，直接叙述：
   - 不写：他说「不要追盘中脉冲」
   - 改写：不要追盘中的脉冲，错过买点就不要做了。
3. 压缩口头语可以，改变原意不行。「是不是出现了一个好的一个买点」可以收成「就是好的做多买点」，但不能把「可能」写成「必然」。
4. 术语按画面校正：口播的「DC」是低吸、「PDB」是 PCB、「cpou」是 CPO、「奥斯康」是奥士康。个股名称以行情软件和交易所简称为准。

## 三、不确定处

一律用括号就地标注，不单列章节、不加脚注区。

| 情况 | 写法 |
|---|---|
| 口播数字听不清 | （我口播还提过 65 块 2 到 63 块，画面缺口标注不清，区间待确认） |
| 口播与盘面数据冲突 | （我口述它没怎么跌，实际当日 -4.97%，属相对抗跌） |
| 名称转写存疑 | （此名为口播转写，对应标的待确认，可能是宁波东力） |
| 自述战绩无凭证 | （此为直播中的自述，未附交割单） |

## 四、三章各自要写什么

**一、大盘情绪判断**：盘面定性、涨跌原因（分条）、积极信号、后市预期、操作定性、情绪结构（连板高度、退潮信号、资金跷跷板）。数字缺精确值时标「概数」。

**二、交易方法**：买点规则、选股标准、被命名的模型（要件逐条拆开）、位置判断（缺口/均线/前高）、卖出规则、仓位与节奏、战绩自述。方法必须完整到能照做，不能只写结论。

**三、个股区间与理由**：一张表，行=标的，列=维度，5 列封顶：

| 标的 | 方向 | 我给的位置 | 我的理由 | 当日实际 |

- 同一只票的不同动作（买、减、已止盈）分行写，不要挤在一格里。
- 方向只用：买（等回踩）/ 买（已执行）/ 减或卖 / 卖 / 已止盈 / 持有或做 T / 观察 / 规避。
- 理由写讲师给的依据（形态、板块地位、指标、业绩），不写自己的判断。
- 最后一列是事后对照数据，标明日期，不改变前面给出的区间。

## 五、排版

- 空段由 `render_xml.py` 统一生成，**不要在 JSON 里手工塞空字符串段落**：章节标题前 1 个空段、小标题前 1 个空段（紧跟章节标题时不留）、列表与表格后 1 个空段、任何位置不出现连续两个空段。
- 小标题独立成行、加粗，后面不带冒号；正文另起一段。
- 列表：有顺序用 `ol`，并列用 `ul`；每项结尾带标点。
- 表格单元格里不要出现竖线，避免破坏结构。
